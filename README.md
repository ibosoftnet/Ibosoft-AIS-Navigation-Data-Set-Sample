# Ibosoft AIS – Navigation Data Set (Sample)

This repository provides a **sample** of the Ibosoft AIS Navigation Data Set
(AIXM 5.2 + GeoPackage) for **testing and evaluation purposes only**.

> ⚠️ **Not for operational use.** The data in this repository is a sample, is
> not kept up to date, and must not be considered valid or current
> aeronautical information.

## Where is the current data?

The actively maintained, up-to-date data set is published on the
**Ibosoft AIS Developer Portal**: <https://ibonav.aero/>

## Use with Ibosoft Aeronautical Charting

[Ibosoft Aeronautical Charting](https://github.com/ibosoftnet/aeronautical-charting)
is prepared to be compatible with this data set. You can use this sample to
try the charting project before working with the current data.

## Download

The data files are attached to the
[Releases](https://github.com/ibosoftnet/Ibosoft-AIS-Navigation-Data-Set-Sample/releases)
of this repository (one release per sample cycle).
